# Customer Operations Docs

## Purpose

This folder maps the main school-facing launch and implementation documents.

## Recommended Starting Order

1. `SCHOOL_CLIENT_LAUNCH_PACKET.md`
2. `SCHOOL_WELCOME_PACK.md`
3. `SCHOOL_WELCOME_EMAIL_TEMPLATE.md`
4. `SCHOOL_IMPLEMENTATION_GUIDE.md`
5. `ONBOARDING_EMAIL_TEMPLATE.md`

## Use Cases

- Need a polished all-in-one launch document: use `SCHOOL_CLIENT_LAUNCH_PACKET.md`
- Need a shorter pack for onboarding context: use `SCHOOL_WELCOME_PACK.md`
- Need an email-ready version: use `SCHOOL_WELCOME_EMAIL_TEMPLATE.md`
- Need the more detailed school-facing implementation guide: use `SCHOOL_IMPLEMENTATION_GUIDE.md`
- Need the short onboarding information-request email: use `ONBOARDING_EMAIL_TEMPLATE.md`
