## Stage 1: Qualification

- [ ] Lead captured with full contact details
- [ ] Decision maker confirmed
- [ ] School size and use case confirmed
- [ ] Recommended plan confirmed
- [ ] Commercial risks or special requests noted

## Stage 2: Pre-Onboarding Inputs

- [ ] Authorized signatory received
- [ ] Billing contact received
- [ ] Branding assets received
- [ ] Data import files received or waived
- [ ] Training availability received
- [ ] Terms or contract exceptions reviewed

## Stage 3: Account Setup

- [ ] School organization created
- [ ] School code verified
- [ ] Proprietor account created
- [ ] Tenant isolation verified
- [ ] Welcome and login instructions sent

## Stage 4: Plan And Billing

- [ ] Final plan selection confirmed
- [ ] Student count reviewed for billing
- [ ] If Free: account activated
- [ ] If Basic/Premium: payment initialized
- [ ] Payment confirmed in EduPulse SMT before activation
- [ ] Billing contact notified of plan status

## Stage 5: Data Import

- [ ] Import owner confirmed on school side
- [ ] Files validated
- [ ] Backup or rollback point created
- [ ] Dry run completed where needed
- [ ] Import exceptions resolved
- [ ] Production import completed
- [ ] Sample record verification completed with school

## Stage 6: Kickoff And Training

- [ ] Kickoff session scheduled
- [ ] Proprietor attended
- [ ] Admin / headmaster attended
- [ ] Core workflows demonstrated
- [ ] Support path explained
- [ ] Billing visibility explained

## Stage 7: First-Week Activation

- [ ] First login completed
- [ ] Teachers added
- [ ] Students added
- [ ] Attendance recorded
- [ ] Payment or finance workflow tested
- [ ] Branding / report settings configured
- [ ] Follow-up completed within 3-7 days

## Stage 8: Activation Sign-Off

- [ ] School is operational in production
- [ ] No blocker remains for daily use
- [ ] Current status marked as `Activated`
- [ ] Internal notes updated
- [ ] Next checkpoint scheduled

## Risk Flags

Mark any that apply before sign-off:

- [ ] Payment pending or partially verified
- [ ] Data import incomplete
- [ ] Training missed by key school owner
- [ ] School not using core workflows yet
- [ ] Open support blocker
- [ ] Custom commercial exception exists
