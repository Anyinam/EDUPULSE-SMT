# EduPulse SMT Onboarding Checklist Template

## How To Use This Template

1. Copy this file for each new school.
2. Rename it using the format `onboarding-<school-code>.md`.
3. Fill in the school record before kickoff.
4. Update status during onboarding instead of keeping notes in scattered chats.
5. Archive the completed checklist when the school reaches activated status.
