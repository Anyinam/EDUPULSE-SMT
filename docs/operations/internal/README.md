# Internal Operations Docs

## Purpose

This folder maps the main internal documents used to run onboarding, coordination, escalation, and incident communication.

## Recommended Starting Order

1. `BUSINESS_OPERATIONS_INDEX.md`
2. `STANDARD_OPERATING_PROCEDURES.md`
3. `OPERATIONS_HANDOFF.md`
4. `INCIDENT_UPDATE_TEMPLATE.md`
5. `ONBOARDING_CHECKLIST_TEMPLATE.md`

## Use Cases

- Need the official runbook: use `STANDARD_OPERATING_PROCEDURES.md`
- Need the full business docs map: use `BUSINESS_OPERATIONS_INDEX.md`
- Need a live coordination sheet: use `OPERATIONS_HANDOFF.md`
- Need incident comms language: use `INCIDENT_UPDATE_TEMPLATE.md`
- Need to start onboarding one school: use `ONBOARDING_CHECKLIST_TEMPLATE.md`
