## Use Cases

- Need the official runbook: use `STANDARD_OPERATING_PROCEDURES.md`
- Need one single-file legal dossier to forward immediately: use `LEGAL_COUNSEL_DOSSIER.md`
- Need one consolidated legal packet for counsel: use `LEGAL_COUNSEL_PACKET.md`
- Need the exact send-list for counsel: use `LAWYER_DOCUMENT_CHECKLIST.md`
- Need a ready-to-send lawyer cover note: use `LAWYER_COVER_EMAIL.md`
- Need the shortest lawyer-facing summary: use `LAWYER_EXECUTIVE_BRIEF.md`
- Need the full business docs map: use `BUSINESS_OPERATIONS_INDEX.md`
- Need a lawyer-facing technical explanation of the system, Paystack routing, and cryptography: use `LAWYER_TECHNICAL_SYSTEM_SUMMARY.md`
- Need the main IP and confidential-know-how inventory: use `IP_ASSET_INVENTORY.md`
- Need the Ghana data-protection control mapping: use `GHANA_DATA_PROTECTION_TECHNICAL_BRIEF.md`
- Need the planned analytics warehouse and anonymization design memo: use `ANONYMIZED_ANALYTICS_ETL_MEMO.md`
- Need the founder-side legal and confidentiality action checklist: use `FOUNDER_IP_AND_CONFIDENTIALITY_CHECKLIST.md`
- Need a draft contributor IP assignment form: use `CONTRIBUTOR_IP_ASSIGNMENT_TEMPLATE.md`
- Need a draft confidentiality/NDA form: use `CONFIDENTIALITY_NDA_TEMPLATE.md`
- Need a live coordination sheet: use `OPERATIONS_HANDOFF.md`
- Need a filled coordination-sheet example: use `OPERATIONS_HANDOFF_SAMPLE.md`
- Need incident comms language: use `INCIDENT_UPDATE_TEMPLATE.md`
- Need a filled incident comms example: use `INCIDENT_UPDATE_SAMPLE.md`
- Need to start onboarding one school: use `ONBOARDING_CHECKLIST_TEMPLATE.md`
- Need a completed onboarding example: use `ONBOARDING_CHECKLIST_EXAMPLE.md`
