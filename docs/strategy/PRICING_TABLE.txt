SECURITY AND COMPLIANCE
-----------------------------------------------------------------------
All plans include:
- Data encryption at rest
- HTTPS/TLS transport security
- Multi-tenant data isolation
- JWT authentication and RBAC
- Security headers and rate limiting
- Password hashing
- Ghana Data Protection Act support baseline
- Tamper-evident financial ledger

Higher-tier differences:
- School OS improves operational workflows and DSAR handling
- School OS Plus adds the strongest governance, reconciliation, and custom reporting support

=======================================================================

UPGRADE TRIGGERS
-----------------------------------------------------------------------
Free to School OS
- Need editable attendance, feeding, and finance operations
- Need more than one class
- Need lesson notes, inventory, and reporting workflows

School OS to School OS Plus
- Need unlimited scale
- Need advanced analytics or custom templates
- Need stronger reconciliation and governance tooling

Add AI Pack
- Need student rescue workflows, narratives, or exam intelligence

Add Automation Pack
- Need webhook-driven payment automation and auto-reconciliation
