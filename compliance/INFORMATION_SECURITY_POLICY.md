# Information Security Policy

Effective Date: February 21, 2026

## 1. Purpose

This policy defines EduPulse's security controls to protect personal data and system integrity.

## 2. Access Control

- Role-based access for all users.
- Strong password requirements.
- Multi-factor authentication for admin accounts (recommended).

## 3. Data Protection

- TLS encryption in transit.
- Encryption at rest for databases (where supported).
- Secure secrets management.

## 4. Monitoring and Logging

- Centralized audit logs of critical actions.
- Alerts for suspicious access patterns.

## 5. Backup and Recovery

- Daily automated backups.
- Tested restore procedures.
- Backup retention according to policy.

## 6. Vulnerability Management

- Regular dependency updates.
- Security patches applied promptly.
- Annual penetration testing (recommended).

## 7. Incident Response

- Incident response plan with defined roles.
- Breach notification procedure.

## 8. Training

Staff receive periodic security awareness training.

## 9. Review

This policy is reviewed annually or after major incidents.
